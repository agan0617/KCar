# 賽道格式 v2

1.0 起的賽道一律用這個格式。舊格式（全程同寬、兩側全是護牆、物理只看中心線）不再支援。

## 檔案

| 檔 | 誰產生 | 內容 |
|---|---|---|
| `tools/blender/<id>_layout.json` | 手寫 | 賽道設計（下面〈layout〉） |
| `assets/<id>.glb` | `build_track2.py` | 畫面用的模型（路面、地形、護牆、場景物件） |
| `assets/<id>_path.json` | `build_track2.py` | 主線中心線：算圈數、名次、電腦走線、小地圖、重生點 |
| `assets/<id>_col.json` | `build_track2.py` | 碰撞：地面三角形（含地面種類）＋護牆線段 |

同一份 layout 同時產生三個輸出，畫面、物理、走線永遠對得上。

## layout

```jsonc
{
  "id": "harbor", "name": "星空港灣", "theme": "harbor", "difficulty": 4, "laps": 3,
  "note": "設計說明（給人看）",
  "defaults": { "w": 7.5, "bank": 0, "curb": 1.0, "wallL": "wall", "wallR": "wall", "run": 3.0, "edge": "grass" },
  "points": [
    { "p": [0, 0, 0] },                                   // [x, z, y]，閉合迴圈（最後一點會接回第一點）
    { "p": [120, 0, 2], "w": 9 },                         // 路面半寬（公尺，不含路緣石）
    { "p": [180, 40, 4], "bank": 12, "wallR": "none" },   // 傾斜彎、右側不放護牆（開放路肩）
    { "p": [200, 110, 6], "gap": true },                  // 這一點到下一點之間沒有路面（跳台的缺口）
    ...
  ],
  "boost":     [ { "at": 6.4, "d": 0, "len": 10, "w": 3 } ],     // 加速帶：at＝控制點索引＋小數（6.4＝第 6 點往第 7 點 40% 處），d＝橫向偏移（右正）
  "shortcuts": [ { "from": 9.2, "to": 11.6, "via": [[x, z, y], ...], "w": 3.5, "surf": "dirt" } ],
  "hazards":   [ { "type": "lava", "poly": [[x, z], ...], "y": -2 } ],  // 掉進去就重生（熔岩、水、深谷）
  "props":     [ { "kind": "torii", "at": 3.5, "d": -14, "rot": 0 } ]   // 指定位置的地標（其他場景物件由主題自動撒）
}
```

每個控制點的欄位（沒寫就用 `defaults`，再沒有就用上面的預設值；兩點之間平滑內插，字串欄位取前一點的值）：

| 欄位 | 意思 |
|---|---|
| `p` | `[x, z, y]`，中心線控制點（Catmull-Rom 平滑） |
| `w` | 路面半寬（公尺）。一般 6～10；窄路 4.5 以上 |
| `bank` | 路面側傾（度），正值＝右側低（右彎用正值、左彎用負值）。上限 25 |
| `curb` | 路緣石寬（公尺），0＝沒有 |
| `wallL`／`wallR` | `"wall"` 護牆、`"none"` 不放（開放路肩，車可以開出去）、`"rail"` 低護欄（物理同 wall） |
| `run` | 護牆離路緣石外緣多遠（公尺）；`none` 時是路肩寬，路肩外接地形 |
| `edge` | 路肩材質：`grass`、`sand`、`snow`、`dirt` |
| `gap` | `true`：這一點到下一點之間沒有路面（跳台缺口），前一段要做成上坡起跳 |
| `tunnel` | `true`：這一段加隧道外殼（只有畫面） |

`at`：控制點索引＋小數，用來指定賽道上的位置。

**立體交叉**：兩段路在平面上交叉時，`y` 相差 7 公尺以上就自動做成橋（上層路面＋橋墩），物理會分上下層。

## `<id>_path.json`

```jsonc
{
  "id": "...", "name": "...", "theme": "...", "difficulty": 4, "laps": 3,
  "step": 2.0,            // 取樣間距（公尺）
  "length": 1520.3,       // 一圈長度
  "pts":  [x, y, z, ...], // 主線中心線取樣點
  "hw":   [...],          // 每個取樣點的路面半寬
  "bank": [...],          // 每個取樣點的側傾（度）
  "gap":  [0, 0, 1, ...], // 每個取樣點是不是在缺口上
  "start": 0              // 起終點線的沿線距離
}
```

## `<id>_col.json`

```jsonc
{
  "tris":  "<base64 Float32Array>",  // 每個三角形 9 個數：x0 y0 z0 x1 y1 z1 x2 y2 z2
  "surf":  "<base64 Uint8Array>",    // 每個三角形一個地面種類（下表）
  "walls": "<base64 Float32Array>",  // 每段護牆 6 個數：x1 z1 x2 z2 y底 y頂（垂直的牆面，車是半徑 0.85 的圓）
  "killY": -30                        // 掉到這個高度以下就重生
}
```

地面種類：

| 值 | 名稱 | 效果 |
|---|---|---|
| 0 | road | 路面 |
| 1 | curb | 路緣石（震動） |
| 2 | grass | 草地、泥地：大幅減速 |
| 3 | boost | 加速帶 |
| 4 | dirt | 捷徑的土路：小幅減速 |
| 5 | hazard | 熔岩、水：重生 |
| 6 | sand | 沙地、雪地：大幅減速（比草地更慢） |

碰撞只收車子碰得到的面：路面、路緣石、路肩、加速帶、地形（賽道附近、車開得到的範圍）、橋面、跳台。
場景物件（樹、房子）不進碰撞；路肩外如果有車不該去的地方，用護牆或地圖邊界牆擋住。
**地圖邊界**：地形可行駛範圍外緣一律加一圈護牆（`walls`），車不可能開出地圖。
